TwoKit Text Style Importer

Import text styles from TwoKit into your Figma file

📄

Drop your figma-text-styles.json file here
or click to browse

📋

How to use:
1. Generate text styles in TwoKit web app
2. Export "Figma Text Styles" JSON file
3. Upload the file here and click Import
4. Styles will appear in your Figma file's text styles panel
